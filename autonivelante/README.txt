AUTONIVELANTE PRO PWA

1. Sube todo el contenido de esta carpeta al repositorio de GitHub.
2. Activa GitHub Pages en Settings > Pages.
3. Abre la URL publicada en Safari del iPad.
4. Pulsa Compartir > Añadir a pantalla de inicio.
5. Inicia sesión con el mismo usuario de Firebase que utilizas en Dietas.

Los datos se guardan en:
users/{uid}/autonivelante/currentProject

No se sobrescriben los datos de Dietas.
